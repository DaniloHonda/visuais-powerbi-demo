Visuais para Power BI

Biblioteca de visuais personalizados em TypeScript. O código desta página é o mesmo que vira .pbiviz: ele roda aqui no navegador, sobre uma base fictícia — clique, filtre, ordene, busque e exporte como faria num relatório.

Todos os dados desta página são fictícios. Pessoas, vagas, datas e números foram inventados para a demonstração. Nenhum dado real.
